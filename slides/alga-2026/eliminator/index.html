      GUIA RÁPIDO

      Forma escalonada reduzida

      Usa operações elementares para chegar à forma escalonada reduzida por linhas. O primeiro elemento não nulo de cada linha é o seu pivô.

      120−1
      0013
      0000
      Os pivôs estão assinalados a verde.
      1. As linhas nulas ficam no fim.
      2. O primeiro elemento não nulo de cada linha é 1.
      3. Cada pivô está à direita do pivô da linha anterior.
      4. Os restantes elementos de cada coluna com pivô são zero.

      Podes somar um múltiplo de outra linha, multiplicar uma linha por um número não nulo ou trocar duas linhas. Há vários caminhos válidos. Experimenta e usa Desfazer sempre que precisares.

      Nos sistemas, a última coluna contém os termos independentes. Cada operação aplica-se à linha inteira, incluindo essa coluna. Uma linha do tipo 0 = 1 indica que o sistema não tem solução. Depois de reduzir a matriz, identifica as variáveis dependentes e introduz o conjunto-solução. As variáveis livres mantêm os seus nomes e podem assumir qualquer valor real; preenche as constantes e os coeficientes com inteiros ou frações.
